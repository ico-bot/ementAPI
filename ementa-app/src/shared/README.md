# Núcleo Compartilhado (`src/shared`)

Este diretório centraliza código genérico, agnóstico de regra de negócio específica, que pode ser importado por qualquer módulo ou página da aplicação.

## Subdiretórios
- `components/`: Componentes visuais genéricos (Design System UI base e Layouts globais).
- `services/`: Utilitários de rede, clientes HTTP e helpers de mock.
- `types/`: Tipagens utilitárias transversais.
