# Componentes Compartilhados (`src/shared/components`)

Componentes visuais genéricos e puramente apresentacionais construídos com **React**, **TypeScript Estrito** e **Tailwind CSS**.

## Subpastas
- `ui/`: Elementos atômicos e moleculares do Design System (ex: Botões, Modais, Inputs, Spinners).
- `layout/`: Estruturas visuais de página (ex: Header, Sidebar, Container Principal).
