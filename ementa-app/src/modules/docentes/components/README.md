# Componentes do Módulo de Docentes

Este diretório armazena os componentes visuais reutilizáveis para exibição e filtragem de docentes da instituição.

## Componentes

- **`DocenteCard.tsx`**: Card interativo com efeito glassmorphism apresentando o professor, suas titulações em badges e resumo de disciplinas lecionadas.
- **`DocentesFilterBar.tsx`**: Barra de filtros e busca em tempo real por nome, titulação ou cargo acadêmico.
- **`DocenteDetailModal.tsx`**: Modal completo exibindo o perfil do docente, suas coordenações e a grade detalhada de disciplinas lecionadas por curso e semestre.
