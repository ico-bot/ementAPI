# Páginas do Módulo de Docentes

Este diretório contém os componentes de página de nível superior para o roteamento do módulo de Docentes.

## Páginas

- **`DocentesListPage.tsx`**: Página principal que renderiza o catálogo completo de docentes da instituição, conectando a barra de filtros (`DocentesFilterBar`), a lista de cards (`DocenteCard`) e o modal de perfil e disciplinas (`DocenteDetailModal`).
