# Modais do Módulo de Disciplinas (`src/modules/disciplinas/components/modals`)

Este diretório armazena os modais de interação, formulários de cadastro/edição e visualizadores de detalhes das disciplinas.

## Arquivos
* **`EditDisciplinaModal.tsx`**: Modal de criação e edição de disciplina.
* **`DisciplinaDetailModal.tsx`**: Visualizador detalhado unificado suportando tanto as matrizes curriculares quanto o catálogo geral.
* **`DeleteConfirmationModal.tsx`**: Modal de confirmação de exclusão de disciplina.
