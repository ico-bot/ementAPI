# Componentes de Listagem (`src/modules/disciplinas/components/list`)

Este diretório agrupa os componentes responsáveis pela renderização e exibição de coleções de disciplinas, tanto em formato tabular quanto em cards visuais.

## Arquivos
* **`DisciplinasTable.tsx`**: Tabela principal de listagem do catálogo geral de disciplinas.
* **`DisciplinaCard.tsx`**: Card visual compactado para exibição individual de matéria na grade curricular.
