# Componentes da Matriz Curricular (`src/modules/disciplinas/components/matriz-curricular`)

Este diretório contém os componentes estruturais e visuais exclusivos para a montagem e renderização da grade/matriz curricular dos cursos.

## Arquivos
* **`MatrizCurricularGrid.tsx`**: Grade visual distribuindo as disciplinas por períodos.
* **`CurriculoHeader.tsx`**: Cabeçalho resumindo informações gerais de créditos e carga horária da matriz.
