# Componentes de Listagem de Cursos (`src/modules/cursos/components/list`)

Este diretório armazena os componentes apresentacionais responsáveis por renderizar e formatar os cursos em formato de cartões visuais (cards) ou listas.

## Arquivos
* **`CursoCard.tsx`**: Card exibindo metadados essenciais de um curso (código, nível, turno, status e créditos).
