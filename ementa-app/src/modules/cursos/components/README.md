# Componentes Visuais do Módulo de Cursos (`src/modules/cursos/components`)

Esta pasta armazena os componentes de interface React do domínio de cursos organizados por categoria funcional.

## Estrutura de Diretórios
* **`list/`**: Componentes de exibição em lista ou cards (`CursoCard`).
* **`filters/`**: Componentes de barra de pesquisa e seletores de filtragem (`CursosFilterBar`).
