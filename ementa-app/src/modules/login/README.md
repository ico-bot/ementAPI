# Módulo de Login e Autenticação

Este módulo gerencia a interface e lógica de autenticação dos usuários da aplicação acadêmica.

## Estrutura do Módulo

```bash
login/
├── components/          # Componentes de UI (LoginForm, etc.)
│   ├── LoginForm.tsx
│   └── README.md
├── pages/               # Páginas roteáveis (LoginPage, etc.)
│   ├── LoginPage.tsx
│   └── README.md
├── services/            # Lógica de negócio e serviços de auth (authService, etc.)
│   ├── authService.ts
│   ├── types.ts
│   └── README.md
└── README.md            # Este arquivo
```
