# Login Components

Este diretório contém os componentes reutilizáveis de interface com o usuário referentes ao fluxo de login.

## Componentes

* [LoginForm.tsx](file:///C:/Users/fw-da/Documents/ementAPI/ementa-app/src/modules/login/components/LoginForm.tsx): Componente que renderiza os campos de entrada do formulário (`usuário` e `senha`), gerencia as mensagens de erro local, a ação de clique do botão e dispara o serviço de autenticação assíncrona.
