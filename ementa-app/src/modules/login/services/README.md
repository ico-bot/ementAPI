# Login Services

Este diretório contém os serviços de gerenciamento de sessão e autenticação de usuários da aplicação.

## Arquivos

* [authService.ts](file:///C:/Users/fw-da/Documents/ementAPI/ementa-app/src/modules/login/services/authService.ts): Serviço com funções de validação de login (simulado com as credenciais `admin` / `admin123`), controle de encerramento de sessão (`logout`) e consulta ao estado atual do localStorage (`isAuthenticated`, `getLoggedUser`).
* [types.ts](file:///C:/Users/fw-da/Documents/ementAPI/ementa-app/src/modules/login/services/types.ts): Interfaces de tipagem para as credenciais e respostas do fluxo de login.
